# Code of Conduct

We are committed to making participation in MRX Desktop a respectful and welcoming experience for everyone.

Examples of behavior that contributes to a positive environment:

- Be respectful and constructive when reviewing ideas and code.
- Assume good intent while discussing disagreements.
- Focus feedback on the work, not the person.
- Accept responsibility for mistakes and help repair their impact.

Unacceptable behavior includes harassment, insults, discriminatory language, doxxing, threats, and sustained disruptive conduct.

Project maintainers may edit, reject or remove contributions that violate this code and may restrict participation when necessary. To report an issue, contact the repository maintainers through the private contact method listed in the GitHub repository profile.
