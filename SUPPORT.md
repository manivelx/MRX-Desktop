# Support

MRX is an early-stage community project. Support is best-effort and no compatibility guarantee is currently provided.

- **Bug reports:** GitHub Issues, with exact reproduction steps and logs after removing private data.
- **Design and usage questions:** GitHub Discussions, if enabled.
- **Security issues:** follow `SECURITY.md`; do not post them publicly.

Please include your distribution, kernel, X11 server, GPU and driver, Quickshell version, and the exact commit or archive version. Do not attach passwords, tokens, private keys or unredacted home-directory contents.
